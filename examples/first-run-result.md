# media-script-review 首次使用产物

依据包内审稿标准，只诊断和给建议；共同材料是唯一事实依据。按面向社区小店经营者的短口播判断，未提供标题、封面或发布数据。

## 总判断：先改再用

可保留的看点，是把预约书、待归还书分区，并给预约书标取书日期这一具体做法。“试行一周，记录到一次取错书”也是可以交代的事实。

首要问题是把一项试行写成已经证实、可普遍复制的成功方法。开头“彻底解决”还与后文“一次错拿”直接冲突。当前材料足以讲一次调整经过，不足以支持效率、成本和普遍效果承诺。

## 必须修正的位置

| 原句或位置 | 问题与影响 | 具体修改动作 | 验收标准 |
|---|---|---|---|
| “一家书店只分了两个书架” | 把“同一个书架分成两区”改成了“两个书架”，改变了动作和对象；还漏掉写取书日期这项操作。 | 写清是小林把书架分成两区，并给预约书写取书日期。 | 读者能复述原有两个动作，不会理解成另有两个书架。 |
| “取错书的问题就彻底解决了” | 一周仍记录到一次取错，不能叫彻底解决；没有改动前统计，也不能证明出错率下降。 | 删除“彻底解决”的判断，缩小为“做了调整并试行一周”，后面保留记录和比较限制。 | 全稿不再出现零出错或效果已证实的暗示；一次记录与开头不矛盾。 |
| “过去店员每天都要找很久，现在效率翻倍” | “常要逐本核对”被加成“每天”和“很久”；“效率翻倍”没有计时、工作量或比较口径支持。 | 原来的麻烦只写“店员常要逐本核对”；删除“效率翻倍”，用分区和标日期的具体动作承接。 | 不新增频率、耗时和效率比例；没有把减少核对负担写成已测出的收益。 |
| “试行一周只错拿了一次，这证明管理不用花钱” | 一次错拿是记录，不是成本记录；从这个数字推不出免费，也推不出普遍的管理结论。 | 保留“试行一周，记录到一次取错书”；删除成本推断，并补上缺少改动前统计的限制。 | 数字带着“一周”和“记录到”的范围；不出现未经提供的零成本结论。 |
| “照着做，你的店也能立刻见效” | 一个尚未完成效果比较的个案，被扩成对任何店的即时保证；“照着做”的两项动作也没说全。 | 删除即时效果保证。若保留尝试建议，明确它只是可参考的试行做法，先把两项动作交代完整。 | 读者分得清“可以参考尝试”与“已经保证有效”；不承诺适用于所有店或立刻改善。 |

这些问题可以归为三件事：先纠正做法的转述，再撤掉没有依据的收益，最后把结尾承诺收回材料能支持的范围。无需为了修这些问题另换选题或给人物补冲突。

## 补料范围

按上面收窄成“调整经过与试行记录”，现有材料就能修改，不必先补料。

如果坚持保留“效率翻倍”，至少需要同一任务、同一口径的改动前后工作量与耗时记录，并说明“效率”如何计算；如果要讲出错率变化，需要可比较的前后取书总次数和取错次数；如果要讲成本，需要这次调整的实际成本记录。即使补到个案数据，也不能据此给所有店作出“立刻见效”的保证。

## 这次用了什么

- 承诺与材料逐句对照 → “彻底解决”“效率翻倍” → 把已发生的动作、记录和未证实的效果分开。
- 检查动作是否完整 → “两个书架” → 纠正分区对象，并恢复标取书日期这一步。
- 核对首尾是否一致 → “一次错拿”与“彻底解决”“立刻见效” → 避免正文反驳开头、结尾又扩大结论。
